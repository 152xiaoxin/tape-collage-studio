# 胶带拼贴工作室

一个中文友好的和纸胶带拼贴 Skill，可将照片、产品或文字创意转换成具有真实纸张纤维、半透明叠压和手工撕边质感的胶带拼贴作品。

## 主要功能

- 照片转胶带拼贴
- 忠实保留原图并与胶带重构并置
- 根据文字描述创作胶带画
- 输出透明背景 PNG 胶带素材
- 支持小红书、抖音、快手和电商海报
- 支持精确中文标题排版
- 支持针对已有作品进行局部返修

## 使用方法

将本仓库安装到 Codex Skills 目录，然后使用：

> 使用 `$tape-collage-studio`，把这张照片做成适合小红书发布的胶带拼贴，不要文字。

## 风格特点

作品以真实和纸胶带为核心，强调纸张纤维、半透明叠压、自然撕边、浅接触阴影和充足留白，避免矢量插画感、碎纸马赛克和杂乱手账装饰。
