# 中文提示词配方

只选与当前任务有关的字段。提示词要完整、可执行，但不要重复堆叠同义词。

## 照片转胶带重构

```text
任务：将输入照片转换为一张完整的和纸胶带拼贴成品。
输入角色：图片 1 是唯一主体参考，不是需要原样保留的照片区域。保留【1–3 个识别锚点】、【姿态/轮廓】和【关键配色】。
画幅与用途：【3:4 / 9:16 / 1:1 / 用户指定】，用于【普通作品 / 小红书 / 抖音快手 / 电商】。
构图：采用【极简留白 / 平衡叙事 / 商业主视觉】强度；一个清晰主体，主体约占【比例】，为【文字或产品信息】预留【位置】留白；所有内容远离边缘。
主体构造：用约【数量】块宽或中宽和纸胶带重新搭建主体；保留完整大结构，将相近小色块合并；用相邻明中暗胶带面、叠压次序、负形和少量窄胶带条表达结构，不使用任何绘制轮廓线。
材质：真实哑光和纸胶带，细纤维、柔和毛边、轻微颜料不均、自然半透明；叠压处略深并有窄接触阴影；少量自然撕边、轻折痕和一两个微翘角；整体平面、浅层。
背景：干净暖白色无涂布手账纸，细纤维和纸浆起伏清晰但克制，不偏黄、不脏、不做旧。
颜色：从输入图提取【3–6 色】；保留【必须准确的品牌色/商品色】；最多一个强强调色。
文字：无文字。
必须保持：【用户强调不能改的内容】。
禁止：铅笔线、墨线、粗描边、立体纸雕、塑料贴纸、矢量渐变、密集碎屑、票据、邮票、标签、剪刀、胶带卷、手、桌面杂物、乱码、伪文字、标志、签名、水印。
```

## 纯文字主题生成

```text
任务：创作一张关于【主题/情绪】的和纸胶带拼贴作品。
画幅与用途：【比例与平台】。
视觉命题：用一个【具体主体或象征物】表达【主题】，不要逐字堆砌所有名词。
构图：采用【极简留白 / 平衡叙事 / 商业主视觉】；主体位于【位置】，完整清晰，留白约【比例】。
胶带结构：约【数量】块宽或中宽胶带，以纯色为主，可加入至多两种简单图案；用叠压、负形、明中暗色面和少量窄胶带条构造，不画轮廓线。
材质：真实哑光和纸纤维、半透明重叠、轻微颜料不均、少量撕边、浅接触阴影、克制折痕，保持平面手账拼贴感。
纸张：干净暖白无涂布纸，细纤维可见，不偏黄、无污渍和重度做旧。
配色：【3–6 色方案】，最多一个强调色。
文字：无文字。
禁止：无关手账装饰、票据、邮票、旧照片、工具、桌面杂物、碎屑马赛克、数字渐变、乱码、标志、签名、水印。
```

## 原图并置所需的透明胶带主体

```text
任务：根据输入照片生成一个用于后期并置排版的独立胶带重构主体。
输入角色：图片 1 仅提供主体、轮廓、姿态和配色参考；不要输出照片矩形或原照片碎片。
输出：一个完整、无文字、孤立的胶带主体，背景必须为真正透明 RGBA；主体四周有透明安全区，任何胶带边缘和内部叠压阴影都不能被裁切。
主体构造：保留【识别锚点】，用约【数量】块宽或中宽和纸胶带构成；使用明中暗色面、负形、叠压接缝和少量窄胶带条表达结构。
材质：哑光纸纤维、柔和毛边、半透明重叠、窄内部接触阴影、少量撕边和克制折痕；保持平面浅层，不做纸雕。
文字：无文字。
背景约束：除主体外必须透明；不生成纸张、白底、纸色矩形、棋盘格、相框、扫描纹理、整块阴影或边缘色晕。
禁止：照片碎片、铅笔墨线、密集碎屑、票据、邮票、标签、工具、乱码、标志、签名、水印。
```

## 产品胶带海报

```text
任务：把输入产品提炼成适合【平台】的胶带拼贴商业主视觉。
识别优先级：严格保留产品【瓶型/盒型/比例/主色/标签色区/关键图形关系】；不要改成另一种包装。
构图：画幅【比例】，产品胶带主体占宽度约【比例】，放在【位置】；在【位置】保留干净文案区；不自动生成任何营销文字。
结构：用 16–30 块有明确功能的宽、中宽胶带搭建产品轮廓与体积，标签文字区域只做色块占位；若必须保留精确标签文字，应改用原图并置或后期排字。
风格：真实手工和纸胶带、清晰纤维、半透明叠压、自然撕切边、浅接触阴影；具有商业设计秩序，避免幼儿手工感和杂乱手账感。
背景：【干净暖白纸 / 用户指定背景】。
禁止：改产品轮廓、改变品牌色、生成假标签字、增加不存在的配件、票据、邮票、工具、桌面杂物、乱码、水印。
```

## 精确文字后期

先生成无字图，再用脚本叠字。不要让生成模型为普通标题重做整张图。

```bash
python scripts/add_exact_text.py \
  --image input.png \
  --output final.png \
  --text "精确标题" \
  --position lower-left \
  --size-ratio 0.045 \
  --color "#514b45"
```

支持位置：`upper-left`、`upper-center`、`upper-right`、`center`、`lower-left`、`lower-center`、`lower-right`。如需人工指定位置，使用 `--x` 和 `--y`，数值为画布宽高的 0–1 比例。

## 定向返修

```text
只修正：【单一失败属性】。
保持不变：【主体】、【姿态】、【胶带结构】、【配色】、【构图】、【画幅】、【背景】以及【精确文字或无字状态】。
具体修正：把【问题】改为【清晰可观察的目标】。
不要增加任何新主体、装饰、文字、标志、签名或水印。
```

## 快速质量诊断

| 失败表现 | 定向修正 |
| --- | --- |
| 像矢量插画 | 加强纸纤维、边缘毛糙、半透明重叠和轻微颜料不均；取消数字渐变与统一描边 |
| 像碎纸马赛克 | 合并相近色块，改用更少、更大的胶带结构面 |
| 像立体纸雕 | 压低体积阴影，改成正面平贴和窄接触阴影 |
| 主体不认识 | 恢复最关键的 1–3 个轮廓或姿态锚点，删除无关细节 |
| 画面太空 | 放大主体或增加一个源自输入的环境呼应，不加通用装饰 |
| 画面太满 | 删除次要元素，缩小环境呼应，恢复安全边距 |
| 纸张太脏 | 保留局部细纤维，去掉黄变、云斑、水渍、颗粒和做旧 |
| 文字错误 | 保持图像不变，删除模型文字，使用脚本重新叠加精确文字 |
| 产品不像 | 恢复包装比例、主色和色区关系；若标签文字必须精确，使用原图并置 |
